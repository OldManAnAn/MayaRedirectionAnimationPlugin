# Maya Redirection Animation Plugin

## 当前使用中的脚本

- `Retarget Tool Optimized/WretargetToolOptimized.py` — 当前 Retarget Tool 主脚本
- `动画片段关键帧起始点设为 0 脚本.py` — 将动画片段关键帧起始点设为 0
- `骨骼动画脚本技巧-批量将骨骼绘制样式改为骨骼.py` — 批量将骨骼绘制样式改为骨骼

## 旧版本与备份

旧版 Retarget Tool 脚本统一存放在 `backups/Retarget Tool Optimized/`，仅用于回溯或对比，当前不作为主入口。
